# Doodeley

A drawing game where you sketch a word and AI Model guesses what you're drawing

## Play

[Click here to play](https://melodelete.github.io/Doodely/)

## Features

- **Undo / Clear** undo up to 25 strokes, or clear the canvas entirely
- **Timer ring** a circular progress indicator that changes color as time runs out
- **Score & streak tracking**  your score ,current streak, And Best streak
- **Difficulty** There are 3 modes,Easy, Normal, and Hard,
- **Skipping** You can Skip words if it is too difficult or The AI Cant Guess it
- **Advancements** There are 4 Achievments for doodeling 3/5/10 times in a row,And finishing under 10 seconds.
- **Hotkeys** There is currently only one hotkey which Is S to skip a word

## Tech Stack

| **AI Model** | [DoodleNet](https://learn.ml5js.org/#/reference/doodle-net) via [ml5.js](https://ml5js.org/) 0.12.2 |
| **Fonts** | [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts |
| **Dependencies** |A webby webby browser
